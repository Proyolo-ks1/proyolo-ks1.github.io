What do these badges mean?

Development: Indicates whether a project is still being developed, completed, or archived.

Functionality: Indicates whether the project currently works, partially works, or doesn't work.

Tags: Describe the type or purpose of a project, such as Game, Educational, or Experimental.

Languages: Programming languages automatically detected from the project's GitHub repository.
